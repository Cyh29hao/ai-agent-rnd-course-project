## 仓库怎么组织

```text
materials/    现有稿件、PPT/PDF、来源、媒体及可复现材料
docs/         项目状态、历史方案、协作说明、存档清单
automation/   自启动脚本与配置模板
.github/      简短的反馈和修改模板
```

`materials`内部路径保持原样，以便已有制作与校验脚本继续使用。历史文件保留日期和原结论；与新需求冲突时，以本页及最新样稿为准。[材料存档清单](docs/材料存档清单.json)校验文件字节，不评判汇报质量。
