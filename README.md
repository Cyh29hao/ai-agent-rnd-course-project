### 拿到材料后怎么做

1. 打开并保存本人的素材页和配套PDF，先看懂自己负责的内容。
2. 助教发布要求后，把正式要求、这两份材料和自己的风格偏好交给AI，复制素材页内的提示词即可。
3. 本人通读修改，补充真实贡献与个人体会，核对图、数字和引用，再按要求提交。

四份报告的主体和个人总结应体现各自工作。素材是写作依据，AI生成后仍由本人确认；页数、格式、提交入口和截止时间等待正式通知。
