### 我们要不要做“自己的RSI实验”？

**最新决定：可选增强，未启动，不列必做。** 如果太难就不做，行业案例主讲仍可独立完成。曹天卓可以在本人愿意、资源合适时考虑承接，**目前没有指派给他**。其他人照常推进自己的部分，不等待实验。

讨论过两条路线：

| 路线 | 真正改什么 | 当前建议 |
|---|---|---|
| **Agent程序自改** | 修改自己的工具、规划、记忆或代码；改进后的A₁继续研发A₂ | 若有人自愿且设备合适，可先尝试一次最小循环。权重固定也能研究代码层自改；性能提升仍需实际测 |
| **模型权重更新** | 训练得到M₁，再由M₁接棒研发M₂ | 工程与算力负担更高，暂不作为主路线；没有选定或启动 |

当前陈云海电脑检测到Intel Iris Xe核显、约15.7GB内存，未检测到NVIDIA独显；**这只说明当前电脑，不代表全组资源**。本地小量化模型推理可考察，但能否可靠修改自身程序尚未实测；不预先承诺基准成绩。

如果以后尝试：我们可用Codex搭初始底座，正式自改轮次要记录由哪个模型/Agent提出并执行修改。若各版都是人指挥外部Codex改出来，应称人工辅助优化，不冒称被测Agent递归自改。公开基准可考察MLE-bench、RE-Bench，采用原评分方法、固定预算并说明任务子集；**它们衡量任务能力，递归是否发生还需版本接棒记录。** 具体方案未定，不为实验新增下载、训练或整套复现要求。

有可讲结果时，再讨论放进D段的1—2页、约60—90秒，并替换部分已有讨论、重新核算总时长。没有结果就保留现有结论；不预留一章等待实验，不把提示词截图当成RSI证据。[完整实践选择与参考项目](docs/实践选项与旧实验说明.md)

### 旧的“24题、16题、13分和12分”是什么？

这是之前**让Agent查原文、判断报告说法是否准确**的一套演示，现已不作为主讲实践：

- **24题**是计划用来找错误、改操作步骤的“练习卷”，不是训练大模型的24条数据；这部分没有完成运行。
- **16题**是两种提示方法实际做过的演示题。所谓“16题补测”是后来打算另准备没提前见过的题再测，现已取消必做要求。
- 原始成绩是**13/16与12/16，不是13/24与12/24**：表示答案与预设标签一致的题数。不是研发能力分，也没有证明某版更强；部分标签有争议，题目与答案也没有真正隔离。[原始评分](materials/practice/runs/demo/score.json)
- **逐人实验**是旧方案要求每个人各自操作并留记录，已取消。旧实验里的A/B/C/D操作角色不套用现在的四人讲述分工。

这些历史记录保留原样，**全组无需补跑旧练习卷、小测或逐人实验**。
