## 怎么一起改

按自己顺手的方式做就好：直接改稿、编辑自己的PPT页面，或者让AI Agent协助都可以。交回时说清改了哪一部分、还有什么想讨论，陈云海最后统一合稿。

**会用PR就把改稿提上来，方便大家看差异和讨论；不熟悉PR，直接发文件或提意见也可以。** 不要求固定分支名字、任务编号、修改条数或填完整套模板。Git操作可以交给自己的Codex处理；注意保留其他同学的修改。

查看最近变化：[更新速览](CHANGELOG.md) · [大家的PR](https://github.com/Cyh29hao/ai-agent-rnd-course-project/pulls)。需要操作提示时看[简单协作说明](docs/PR协作与更新速查.md)。
