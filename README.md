课程：大模型与智能体工程实践。这个私有仓库存放四人汇报的稿件、图表、来源和修订记录。现在已有协作者加入。

## 第一次加入，走这四步

1. **理解我们要讲什么：**读[主线与内容地图](docs/项目主线与内容地图.md)，再看[24页主讲PDF](v5/outputs/智能体产业研发_V5_05_主讲.pdf)。历史版本不用通读。
2. **按已定分工选任务：**看[任务板](docs/协作任务板.md)。陈云海先精修A；其余成员优先处理各自段落，跨段建议共同核对。
3. **让自己的Codex开始：**打开本仓库的本地副本，复制[启动提示与具体任务](docs/Codex协作提示词.md)。无需原聊天上下文。
4. **把结果接回来：**按[协作说明](docs/协作说明.md)交一个小提案或PR。提供可以直接替换的文字，让组长逐项判断。

仅想提意见：在Issues写页码和没听懂的一句话即可。

## 合作时守住的主线

**改了什么？怎么知道改好了？这次改进怎样帮助下一轮研发？**

Anthropic展开目标模型训练，OpenAI展开评测流程，Google和开放研究补足算法、策略与代码。我们讨论的是大模型产业研发，不是通用软件研发，也不把不同任务的数字排成公司排行榜。

- 主讲24页，文献2页，答辩8页。约15分钟是设计预算，尚未真人计时和确认教师最终限时。
- 本组实践继续搁置；公司实验未由本组复现，教学短片不是实验录像。没有必做的24题开发集、16题补测或逐人实验。
- 分工已定：A陈云海、B张程翔、C赵金城、D曹天卓。[分工与衔接](docs/分工与衔接.md)；陈云海后续以精修Part A为主，同时审核、统稿和衔接全场。具体修改任务另行登记。
- 修订05已实际原生打开、实测嵌入视频；真人理解、课堂设备和整体课程验收未完成。
- 默认先交提案，组长统一整合源稿与导出文件，避免多人覆盖同一份PPT。
