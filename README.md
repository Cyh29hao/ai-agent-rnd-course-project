## 这场汇报讲什么

Agent的能力依赖模型、工具和行动流程。本组选择AI研发行业，看Agent怎样在人类设定目标与审核下，参与改进这些系统。

共同主线是：**从已有系统出发，Agent提出修改、执行训练或评测，判断效果并保留成果，再看成果如何帮助下一轮研发。** 各案例改变的对象不同，不是训练同一个baseline Agent，也不把全部辅助研发直接等同于RSI。

|---|---|---|
| A｜陈云海（组长） | 01—07 | 简洁封面、独立Inspiration、目录、RSI与autoresearch、案例引入 |
| B｜张程翔 | 08—13 | Anthropic研究流程、激活引导、KL蒸馏、改善空间与搜索条件比较 |
| C｜赵金城 | 14—18 | Codex评测工作流、计划审批与Runme记录、AlphaEvolve程序优化及23%/1%的分母 |
| D｜曹天卓 | 19—24 | Agent策略训练与代码自改、跨案例比较、成果回流与持续研发问题 |

## 课程怎么考核、我们怎么准备

已核第一讲要求：**2—4人组队；答辩50分、报告50分；小组选1人答辩，每位成员分别撰写个人报告。** 报告体现本人负责的内容、做法和体会，组内报告应有差异。依据为第一讲课件第5页及2026年9月14日录播00:14:33—00:15:53；[Canvas原课件](https://oc.sjtu.edu.cn/courses/93028/files/13851378)可供核对。

### 个人报告的最新准备安排（2026-10-29）

组长已询问老师：具体要求将由助教后续安排，**目前先保留资料，等正式通知和模板出来后，再按要求整理各自报告**，不提前锁定格式、页数或提交方式。

- **A／组长：**以整个“Agent for Agent”研究话题为对象，综合B、C、D案例分析Agent参与Agent与AI系统研发的方式、验证依据及研究成果如何帮助下一轮研发。重点是全局分析与结论，适当举技术例子，不把报告限制为A的开场七页。
- **B、C、D：**以各自已有PPT、口播和备课为主体，整理成规范、可独立阅读的个人报告；无需为此新增实验或案例。各人自行选择表达和排版风格，并确认实际贡献、个人体会和引用。
- [个人报告参考提示词（A—D可复制）](docs/个人报告准备与提示词.md)：正式要求发布后，把要求与对应提示词一起交给AI，复用现有图文材料；最终由本人通读、修改和确认。现有共用报告是参考，不是四人同交一份的定稿。
