# 四人操作可用性复审

2026-10-13，只审现有说明，不代四位同学操作。结论：**能看懂各人负责什么，尚不能凭包内说明独立完成第一次 Agent 运行。**`00_先读这里.md`和`06_四人上场卡.md`适合阅读、排练；`practice/四人操作卡.md`列责任，`成员C_独立测试操作.md`列隔离原则，`README.md`列评分合同。缺的不是更多背景，而是从平台入口到原始输出的可照做步骤。

## 最短补丁建议

1. 在`practice/README.md`添“第一次真实 smoke”小节：明确选用的 Codex 或 OpenClaw 入口、如何开**新会话**、可用读网页和写文件工具、模型标识在哪里看、从哪个目录运行。把`protocol_baseline.md`全文作为规则输入；只给`smoke/claims.json`与`smoke/sources.json`，明确**不得给**`smoke/gold.json`。提供可复制的任务提示，要求先打开官方 URL 核`T1-run-evals-plan`，将符合`schema.json`的单个 JSON 保存到新建的本人运行目录，保留平台原始会话及真实工具动作，再运行`validate.py`。`README.md:11-16`现有两条命令只检人工样例，不能充作 Agent 运行；`score.py`只评分，也不启动 Agent。
2. 给出目录与失败示例：如`practice/runs/students/<姓名或匿名ID>/smoke-01/output.json`、`actions.jsonl`、`run_manifest.json`；日志只写实际发生的调用，失败输出也保存。提示词、开始/结束时间、模型、配置、工具权限、文件 SHA-256 放 manifest；未知采样写`unknown`。运行完由本人打开输出核七个字段、读`validate.py`结果，再由另一人核官方原文；不能把片段编号存在等同来源正确。
3. 将报告`04_课程报告.md`“个人分工与撰写段落”改为**填写指南**：本人在完成后写真实姓名、实际写或实质修改的章节、对应修改稿路径、本人 Agent 任务产物与一次接受/纠错理由；未做写“未完成”，不能照抄建议角色。`practice/成员实际记录模板.md`已备字段，可作为签认底稿。
