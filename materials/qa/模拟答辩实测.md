课程课件 `../../课件/大模型与智能体工程实践第一讲.pdf` 实际 PDF 第 5 页：答辩 50 分、报告 50 分，答辩时间写“待定”。原用户交接的 10 分钟陈述加 5 分钟问答用于排练约束；逐字稿的 550 秒页内预算尚未四人连续实测（`01_四人逐字稿.md:7-14,126`）。八问是压力题库，不暗示 5 分钟能逐一回答。

## 1. 技术可复现：请只选第 7 页的谄媚方法，告诉我输入、训练目标、产物和验证；你们自己能复现到哪一步？

**可答：**目标是 Qwen3.5-2B；研究 Agent 用激活引导构造较少迎合的教师分布，未引导的学生用 KL 约束向教师分布靠近，产物是训练后权重。论文还用指定基准、留出测试和能力闸门检查候选。我们没有复现这项训练，只复现了自己证据卡工作流的一次制作代理演示；也没有论文未披露的方向估计细节、完整数据和可控采样配置，不能说“按论文全部复现”。

**定位：**`01_四人逐字稿.md:52-68`；`04_课程报告.md:64-82,119-130`；`02_证据台账.md` E01–E06；`practice/runs/demo/freeze.json:3-9`。

**四项：**准确可 / 有证据部分 / 听得懂部分 / 承认限制可。**失分风险：**若把“KL 学软分布”说完就停，听众仍不知道教师分布如何改变模型权重；若说“我们复现了 AAR”，直接越过实际证据。**必须补：**让 B 用一张现有图口述“教师分布→KL 训练→新权重→独立评测”的四步，并能指向论文具体节与本组未做项；不得填造训练超参数。

## 2. 为什么是 Agent：若我把搜索、训练、评分写成脚本，课程里多了什么智能体技术？

**可答：**固定脚本能按既定方案执行训练和评分；AAR 研究 Agent 会读综述与榜单、提出候选方法、写 mini-paper 和训练代码，并读取反馈决定下一轮。跨会话的论坛、榜单和综述承载状态；代码监控、工具权限和隔离评分构成 Harness。它仍在人工规定的失效类型、目标模型、预算和验收规则内探索。

**定位：**`01_四人逐字稿.md:52-56`；`04_课程报告.md:64-68,115-117`；`02_证据台账.md` E01–E02；`05_答辩题库.md:29-31`。

**四项：**准确可 / 有证据可 / 听得懂部分 / 承认限制可。**失分风险：**“会调用工具所以是 Agent”太薄，无法区别编排脚本。**必须补：**四人各能举出一次“反馈改变下次候选”的可定位环节，并区分 Agent 的选择与脚本的固定执行；这不能挪用为本组四人已操作的证明。

## 3. 闭环与 RSI：论文已让 Agent 读上轮结果并训练新权重，为何下一轮不就是递归自我改进？请给可证伪条件。

**可答：**上轮实验产物可以进入下一轮，已形成受限的实验闭环；训练目标模型权重也可构成局部模型改进。但研究方向、十类失效、基准、预算和审批仍由人或预设流程控制，训练后的目标模型也没有被证明能持续独立开发、全面验证并继承更强后继系统。要推翻我们的“未获公开证实”判断，需要看到跨代目标选择、开发、抗投机评测、能力与风险验证以及下一轮持续成功的可审查证据。公开资料缺席不等于系统绝不存在。

**定位：**`04_课程报告.md:20,24-26,98-113`；`01_四人逐字稿.md:44-48,86-90,108-112`；`02_证据台账.md` E16。

**四项：**准确可 / 有证据部分 / 听得懂部分 / 承认限制可。**失分风险：**把人类审批当作自动否决技术能力，或把“持续”说成没有操作判据，都会让四状态像主观口号。**必须补：**答辩时先分“技术自治”与“治理批准”两轴，再说一条可观察的跨代验证要求；不报“距离百分比”。

## 4. 通义同尺度：AgentEvolver 的“策略训练”有没有改模型参数？若有，为什么不与 Anthropic 一起算“局部模型改进”？

**可答：**现稿明确说它围绕任务生成、经验探索、轨迹归因和 Agent 策略训练；比较时应先确认被更新的是哪一层策略及实际交付物。报告把它列为“Agent 策略训练与任务经验”，Anthropic 则有可追踪的目标模型后训练权重和隔离评测。不能仅凭框架开源或“训练”二字，断言通义完成基础模型参数的代际改进；也不能说它完全没有参数更新。现稿没有给通义逐实验的参数更新对象与训练权重定位，细问到具体实验只能承认未核。

**定位：**`04_课程报告.md:28-36,44-46`；`01_四人逐字稿.md:38-48,86-90`；`02_证据台账.md` E14、E16；`05_答辩题库.md:23-25`。

**四项：**准确部分 / 有证据部分 / 听得懂部分 / 承认限制可。**失分风险：**第 11 页把“训练框架”与“Anthropic 改权重”排在一条尺度上，但尚未逐实验说明通义的参数层级，老师可逼问分类是否一致。**必须补：**主讲或备份明确标出 Agent 策略与基础模型权重的不同；若要断言某实验是否更新具体权重，先从 L2 论文核对象、算法和产物再发言。

## 5. 评测选模：AAR 的“留出”参与过选择吗？若选过，图上的好成绩还能叫未接触测试吗？

**可答：**Agent 不可访问留出样本，且隔离评测器读取权重，这降低直接泄漏。但报告已指出留出基准参与从排行榜领先方法中挑选 Petri 审计方法；因此留出既承担验证也进入选择，不能把所有展示结果称完全未触碰的终局测试。Petri 是另外的行为审计，仍只覆盖所设维度；能力闸门也只防显著退化，不证明其他能力不变。

**定位：**`04_课程报告.md:68,70-83`；`05_答辩题库.md:49-51`；`02_证据台账.md` E02、E06。

**四项：**准确可 / 有证据可 / 听得懂部分 / 承认限制可。**失分风险：**逐字稿第 8 页只说“留出测试和开放式审查”，没有主动交代选择步骤；若答成“完全未参与选择的盲测”，会和报告自身冲突。**必须补：**B 答辩卡写清“Agent 隔离样本、研究者选模用留出、Petri 额外审计”三个角色，不把它们混为同一个测试集。

**定位：**`02_证据台账.md` E08；`05_答辩题库.md:45`；`04_课程报告.md:70-83` 可见结果与消融讨论，未见上述人类基线细节。
