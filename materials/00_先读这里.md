## 一条命令复核本地制作包

在本目录打开PowerShell，运行：

```powershell
python _build/verify_package.py
```

它核对页数、备注、媒体嵌入、真实视频解码记录、冻结哈希与实测评分。结果在 `qa/package_verification.json`。它不会替代原文审查、逐页目视、人工金标裁定或真人排练。

重算原始金标分数：

```powershell
python practice/score.py --claims practice/demo/claims.json --gold practice/demo/gold.json --sources practice/sources.json --variant baseline=practice/runs/demo/baseline/outputs --variant candidate=practice/runs/demo/candidate/outputs --out practice/runs/demo/score.json
```

报告重建：`python _build/build_report.py`。PPT重建：`python _build/build_deck.py`，再运行 `_build/export_pdf.py`、`_build/render_qa.py`。Office导出依赖当前可用的Word/PowerPoint。若发生自动化实例错误，应先核对本任务持有的进程和打开文件，不得关闭用户的其他文档。重建后必须重新渲染与核查，旧PDF不算新版验收证据。
