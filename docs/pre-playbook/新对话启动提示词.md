# 新Pre启动提示词

复制下面代码框中的整段文字即可。已知信息可以直接补进去，未知项留空或写“待确认”；不用先把材料整理完才开工。

在本机Codex中，可直接读经验文档路径；在ChatGPT聊天版中，建议同时上传[Pre协作经验](Pre协作经验.md)。无法读取文件时，下面的提示词也包含主要偏好。

```text
这个对话用于协助我准备一场课程Pre。请与我一起把内容做扎实、讲清楚，让我用较少时间真正理解并讲好，而不是拿到一套自己还看不懂的AI成品。

这次已知信息：
- 课程或主题：气味科学中的健康密码（具体汇报选题待定）。
- 时间：预计2026年11月中旬，确切日期待确认。
- 汇报时长、个人或小组、评分重点：待确认。
- 老师要求、课程资料、我已有的想法：我会补充，也可以先查我提供的文件。

请先读取我提供的《Pre协作经验》，本机路径为 D:\桌面\大三上\Pre协作经验\Pre协作经验.md；若在聊天版无法读取本机路径，请使用我上传的同名文件。读不到文件时直接按以下要求开展工作，并说明无法读取的情况。

1. 默认先交“主线、目录与几张样页”，等我认可后再制作全套。先读老师要求和已有材料，复述研究对象、中心问题与暂定答案。缺少会影响路线的信息时集中问我几个问题，同时继续独立准备；资料里能查到的先查。

2. 第一份方案要具体到能评审：为什么值得讲、听众最后得到什么、各段问题与衔接、用时预算、核心依据和媒体安排。样页覆盖几种关键讲法，配对应自然口播、指图和转场，实际看渲染效果。让我能沿着方案理解整场，而不只是看到几个章节名。

3. 全场有明确主线和阶梯，从具体问题和必要基础逐步进入机制、研究与结果。历史或故事解释问题从何而来，不虚构争论；前沿内容讲清新方法怎样解决问题。案例有选择理由，结尾直接回答开头，不靠堆名词、快语速或泛泛展望显得高深。

4. PPT给人看，讲稿给人说。页面按内容选择合适的图示与布局，复杂内容可以拆页。讲稿写成我能直接说出口的完整句子，解释对象、动作和结果，少用“赋能”“闭环”“证据不足”等抽象词替代解释。多媒体承担具体解释任务，并准备静态替代讲法；真实实验、公开素材和教学示意分别说清。

5. 技术、来源和答辩同步准备。核实关键原始资料，说明重要数字的对象、分母、基线和条件，保留能找到原文的定位。回答先给简短解释，再提供深入机制与依据。涉及健康结论时查清研究设计，区分关联、机制与干预效果，不把推测写成健康建议。答辩投入按本课评分决定。

6. 帮我降低机械工作量，也帮我熟悉材料。若是小组，首页概括整场与各段内容，给每位成员口播、图示解释、转场和重点追问；详细资料用链接展开。PR、交文件、直接反馈都可以，技术操作由Agent协助。不要把其他课程的四人分工、页数、实验或评分比例套过来。实践先评估对主题的价值与资源要求，再由我决定。

7. 我认可方案后，请主动完成整套制作和必要检查，普通措辞、布局与技术问题自行处理。重要路线变化再交给我判断。检查实际页面、媒体、出处、材料一致性与时间预算；真人试讲和现场确认尚未做时如实说明。不能仅凭文件生成或自动检查就宣布已经准备好，更不能保证高分。

开始时先给我你对这次任务的理解、最需要补充的少数问题，以及可以立即准备的内容。当前阶段先完成可审阅的方案与样页，不直接重做整套。后续的新偏好和实际验证过的经验，可以补回经验文档，注明哪些已验证、哪些仍是建议。
```

用于其他Pre时，只需修改“这次已知信息”。这段提示词是工作偏好的起点，老师的新要求和用户后续决定优先。
