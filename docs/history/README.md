# 历史方案

这里保留V3、V3.1和后续叙事修订，便于查明修改过程，不要求组员全部阅读。

旧方案曾要求24题开发、提示对照和成员工具记录。2026-10-13最新减负要求已经覆盖这些必做条款；当前以仓库README、docs/项目状态.md和最新口播样稿为准。

`V3压缩包原始清单.json`对应当时压缩包内容，不是当前仓库的文件清单。后来更新了阅读入口和样稿，部分文件字节发生变化，因此原清单只作历史保留。当前材料字节见`../材料存档清单.json`；两种清单都不证明汇报可用性或事实正确率。

仓库使用`.gitattributes`保留materials文件的原始字节，避免Windows自动换行改变冻结哈希。可在仓库根目录运行`python scripts/verify_repository_snapshot.py`，比较本地文件与提交对象；不要求组员为阅读材料运行这条命令。
