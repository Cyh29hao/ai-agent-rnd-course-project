# 汇报叙事修订：先理解任务，再进入技术与证据

来源：2026-10-13用户反馈。当前版本方向大致认可，但实践难懂、目录与线索不清、转换过快，要求有教学阶梯。此文件是下一轮具体改稿依据，尚未替换PPT、稿件或验证新时长。

## 1. 修订目标

贯穿问题：“智能体接过了哪些大模型研发工作？从接手任务到持续开发下一代模型，还差哪些可验证环节？”

教学阶梯：一个具体研发问题 → 工具/状态/反馈的工作循环 → 循环接到模型研发的哪些位置 → 公司真实机制和结果 → 统一RSI判断 → 本组使用同一工程思路核查报告。基础部分只用约30–40秒解释可见工作循环，不重讲一套术语课。

## 2. 目录采用四个明确问题

1. 智能体能接过哪些研发工作？动机、必要工作循环、历史路线与行业地图。
2. 公司实践究竟改了什么？Anthropic的后训练机制与OpenAI的评测工作产物。
3. 这些进展离RSI还差什么？改动对象、验证范围和持续后继研发缺口。
4. 我们怎样使用Agent完成这次研究？一条实际核查任务及真人判断。

每页顶部保持这四段导航并突出当前位置。沿同一张研发地图回指，不让每页引入一套新框架。页标题写本页实际要回答的问题或结论。章节交接补一句“刚才知道什么，接下来要解决什么”。

## 3. 公司案例讲解顺序

Anthropic：先说明迎合错误观点这一任务；再画一次研究Agent→训练工具→独立评测→持久记录的循环；随后只拆一个激活引导＋蒸馏方法，讲清教师分布、学生权重和输出；用一个明确标示的玩具数解释改善空间，再呈现论文结果；不同实验不拼接。

OpenAI：从人写发布前评测目标开始，沿同一工作循环指出计划、人审、工具执行和Runme笔记本。先让听众看懂产物，再讲组织用量与权限事故。以同一尺度比较两家公司，保留Google、通义与DGM的实质位置及选例理由。

历史保留，但口播突出思想问题与证明/经验验证路线的变化；日期、NAS技术细节不要求听众在几十秒内全部记住。主讲10分钟约束不变，重新分配而非加速挤入信息；最终页数与计时须按新版实际检查，不预宣称14页或550秒已适配。

## 4. 实践的真实含义和必须回答的问题

现有实践是来源审查流程：输入公开案例主张；Codex原生代理读来源、判标签、写出处/限制/改写，调用结构校验；评分脚本比较原作者标签。我们制作了两份提示协议、来源索引、schema、校验和评分脚本；没有从零训练模型或实现独立Agent产品。

基线已有来源约束和标签定义。候选额外要求拆对象/动作/分母/权限/时间、查反证、核关键限定，并区分缺证据与否定证据。变化发生在提示SOP；不是平台硬权限或模型权重。24题开发集未跑，候选不是根据真实开发错误优化的版本。

金标由制作代理编写，未由四位成员人工仲裁。原作者标签一致基线13/16、候选12/16，格式均16/16；原标为高风险的八题均未错判supported。不能把分数叫事实准确率，也不能断言候选更差或更好。题目只来自四个事实族，四题类别边界有争议。gold未直接提供到被测提示，但共同工作区未隔离且作者知道答案；不能直接说已证实被测代理读取gold，更不能称盲测。

执行要分人机职责，不能把“工具由Codex调用”误解成“人没有使用Agent”。当前对话发起者已经真实提出研究任务、调整主题、要求加入历史与其他公司、审阅产物、否决不合适的表达并要求重构；这些是使用Agent时的人工决策。具体工具执行由Codex及其子代理承担。可以如实记录“由对话发起者提出任务并评审，Codex执行”，不能把机器写代码说成本人亲手编码，也不能据此代签其他三名成员。还缺可提交的个人协作证据整理、其他成员记录及人工原文判定；不是整组完全没用Agent。

## 5. 实践主讲改成“一条任务走到底”

第一张：为何要核查报告数字 → 给Agent什么 → 工具读取什么 → 得到什么证据卡 → 哪一步待人判断。用具体原主张“65%表示全部安全测试通过”，展示原文所指的十维Petri改善空间口径，输出限定后的改写。仅把角色/执行状态做一句清楚的说明。

第二张：展示真实产物及遇到的问题，“引用片段存在、JSON合格，不等于结论正确”。原标签分数在人工类别仲裁前移入备份，不用13→12作主讲的大数字主线；也不伪造新的有效成绩。metadata=null、包装调用计数、文件路径、冻结哈希和逐项争议放备份/资料包。必要局限保留一句，详证留答辩。

来源审查是我们使用课程方法辅助研究的实践，不能当作已复现Anthropic训练或证明RSI。公司案例承担产业证据，本组实践承担使用Agent和人工评审的证据；两者的连接句要明说。

实践主讲的更真实主线是这次已经发生的人机协作：人提出行业研究问题 → Agent搜索与制作 → 人检查题目偏移、缺目录、视觉单一和指标解释不清 → Agent按反馈修订 → 人继续验收。用当前对话的任务和评审记录配合实际产物版本，先整理事实再由本人核认。两套提示的16题实验可作为来源核查的补充证据，不能让其有争议分数占据实践的全部叙事。24题开发集与错误驱动迭代仍按未完成保留，不借叙事变更追改原计划执行事实。
