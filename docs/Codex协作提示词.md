```text

用不超过250字讲给我听：报告回答什么、为何重点选两家公司、全场怎样推进、本组实践什么状态。接着执行我下一条给你的任务，不提前改整个PPT。

默认交独立修改提案，按docs/修改提案模板.md。在collaboration/proposals/下建立不冲突的短名目录；有我的目录就复用，身份未知写“协作者，待本人确认”。记录git rev-parse HEAD所得SHA，状态写“建议，未进入正式稿”。素材放自己的资产目录。

给具体替换文字，优先质量而非条数。事实核查附文献号、节/图/页；访问失败写未查。本组实践搁置，不加实验；不改成通用软件研发，不把AI模拟听众当真人结果。制作脚本限制按仓库约定处理。

运行python scripts/check_collaboration_docs.py及git diff --check，报告最多三处优先建议（按实际数量；无修改写保留依据）、文件、实际核查、未检项和整合联动。先完成本地文件，PR由后续提交提示授权。
```
