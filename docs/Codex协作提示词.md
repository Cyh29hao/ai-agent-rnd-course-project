```text
保留其他人的修改，涉及相邻段落时说明怎样衔接。帮我解释重要概念和容易被追问的地方，让我真正看懂、能自己讲；不要把生成文件当成我已理解或排练过。PPT完成后看实际显示，讲稿与页面一起检查，交回时简单说明改了什么、哪里还需要我判断。实践可选，不自动启动实验。
```
