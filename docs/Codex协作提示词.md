# 让自己的Codex帮忙

在Codex里打开本仓库，复制下面的通用提示，再补上自己的Part即可。也可以按自己的习惯提要求，不必照抄。

## 通用提示

```text
帮我准备这场《智能体在大模型产业研发中的应用》汇报中自己负责的部分。先读README和我这段的PPT、口播，理解它与全场的联系，再按下面给你的Part开展工作。

我们计划10月31日结束前做好各自初稿，PPT、逐页文字稿和答辩一起准备。我希望内容讲得明白、有技术细节，表达像正常人讲话。请根据内容需要直接改稿或制作候选页面，不用只交建议，也不用限定每次改几处。必要时查原文，说明关键数字和图从哪里来。

保留其他人的修改，涉及相邻段落时说明怎样衔接。帮我解释重要概念和容易被追问的地方，让我真正看懂、能自己讲；不要把生成文件当成我已理解或排练过。PPT完成后看实际显示，讲稿与页面一起检查，交回时简单说明改了什么、哪里还需要我判断。实践可选，不自动启动实验。
```


## 改好后想提PR

```text
帮我把这次改稿提一个PR，简单说明是哪一部分、改了什么、哪里想请大家看看。分支名字和说明不用复杂，保留我和其他人的已有修改。若暂时不能提交，告诉我哪些文件可以直接交给组长。不要替我合并到全组主稿。
```
