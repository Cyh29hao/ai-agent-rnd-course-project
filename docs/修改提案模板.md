# 修改提案模板

复制到自己的`collaboration/proposals/<短名>/`，字段不涉及或没查到如实写明。

```markdown
# T01｜14—23页讲述精修

- 提出者：实际姓名或GitHub短名
- 基准：git rev-parse HEAD所得SHA；当前交付为V5修订05
- 范围：任务、页码、读过的文件
- 状态：建议，未进入正式稿
- 实际做过：逐页读、查原文、朗读或生成示意等
- 没做过：真人测试、重新导出等

## 优先建议（最多三处，按实际数量）

1. 页码、问题、收益各一句。
没有修改建议时写保留依据；多余空项删除，不为凑数新增修改。

## 修改01

- 定位：文件、第几页/段；准确摘相关原句。
- 原文：要换的文字。
- 建议替换：可以直接讲出来的新文字。
- 为什么改：听众在哪里卡住，怎样补上。
- 投影配合：具体到标签/箭头/顺序，或不需要。
- 前后衔接：上一页和下一页怎么接。
- 时间取舍：增加多少设计时间、删掉哪里；不是真人计时。
- 事实依据：文献号、节/图/页、链接；无变化写不涉及。
- 联动文件：JSON script、口播、脚本、报告、答辩等。
- 还没核实：具体剩余问题。

## 组长整合区（提出者留空）

| 修改项 | 决定 | 理由/调整 | 正式修订 | 检查 |
|---|---|---|---|---|
| 01 | 待审 | | | |

提案保存与正式采用分别记录，未采用的内容不当新的事实依据。
```
