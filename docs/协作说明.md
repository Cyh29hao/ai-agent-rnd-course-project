# 怎么用这个仓库

不需要把Git当成额外课程任务。先读README里的材料入口；实验目录不是必读项。

## 只想提意见

点击仓库的Issues → New issue，选择“汇报反馈”。写出页码或一句你没听懂的话就够了。例如：“第7页的教师和学生各是什么？讲稿没有解释清楚。”不知道怎样改也可以提出。

讨论页可以回复和补图。先解决“听不懂”和“没回答题目”，再讨论颜色、字号等细节。

## 想改一小段文字

打开对应Markdown文件，点击铅笔编辑，再提交修改。若页面提供“Create a new branch”选项，建立修改分支并发Pull Request，写清改了哪段和原因。组长也可以统一代交，说明建议来自谁。

名字和章节尚未分配，先不预设每个人的任务。本人读过、审阅或改过什么，就记录什么；不用为了填贡献制造一套额外实验。

## PPT和Word怎么改

下载后编辑，交由组长统一更新，避免几个人同时上传不同版本。尽量附上“改了哪几页/哪一段”的简短说明。尚无新的PPT版本时，不把旧文件改名为V4。

材料现在集中在materials目录，内部路径保持不变。后续版本应标明版本和状态，保留旧稿与原实验，不改历史分数。

## 谁能访问

仓库是private。组长需要在Settings → Collaborators邀请真实GitHub账号；目前没有添加任何协作者。没有GitHub账号的组员可直接接收打包材料、反馈给组长，不必为了这次作业注册并学习Git。

对外提交采用老师要求的格式。仓库合并、自动校验或Agent生成，不代表内容已经可用、本人已理解或排练通过。
