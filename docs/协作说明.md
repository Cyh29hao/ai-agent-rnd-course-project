# 一起改好这场汇报

先看[README](../README.md)里的分工、时间和材料，再改自己负责的部分。需要思路可以看[各段建议](分工与衔接.md)，想让Agent帮忙就复制[自己Part的提示词](Codex协作提示词.md)。这些是参考，不是必须逐项走的流程。

**交回方式怎么方便怎么来：提PR、发文件、直接提意见都可以。** 会用PR时简单写改了哪部分就够了，不熟悉Git可以交给自己的Codex，或由组长帮忙收进仓库。[简单操作说明](PR协作与更新速查.md)

欢迎直接改稿、编辑PPT，也欢迎给其他部分提建议；改到相邻段落时和对方商量。现有材料只是起点，可以按内容需要调整，不限制修改条数和固定格式。
