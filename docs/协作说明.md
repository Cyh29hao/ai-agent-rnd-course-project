# 一起改好这场汇报

先看[README](../README.md)里的分工、时间和材料，再改自己负责的部分。需要思路可以看[各段建议](分工与衔接.md)，想让Agent帮忙就复制[自己Part的提示词](Codex协作提示词.md)。这些是参考，不是必须逐项走的流程。

**交回方式怎么方便怎么来：提PR、发文件、直接提意见都可以。** 会用PR时简单写改了哪部分就够了，不熟悉Git可以交给自己的Codex，或由陈云海帮忙收进仓库。[简单操作说明](PR协作与更新速查.md)

欢迎直接改稿、编辑PPT，也欢迎给其他部分提建议；改到相邻段落时和对方商量。现有材料只是起点，可以按内容需要调整，不限制修改条数和固定格式。

计划10月31日结束前完成自己的完整初稿：PPT、文字稿和答辩准备好，本人认真看过、讲过。陈云海再根据情况安排合稿、修改和排练。

陈云海主要做A并审核全场，各人仍负责熟悉自己的内容。交回时简单说说哪里改好了、哪里还不放心，方便大家接着讨论。

实践是可选项，没有安排给任何人；不用为了实践耽误各段初稿。旧实验留在仓库供查阅，不是大家要补做的作业。

制作整套PPT的脚本有本机依赖，普通改稿不用先搭环境。可以改自己的候选页面或交清楚的图文，让陈云海协调合稿；生成后自己看实际效果。技术细节需要时查[文件地图](项目主线与内容地图.md)。
